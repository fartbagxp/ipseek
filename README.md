# IP Ranger

This is a Rust web application for figuring out where things are hosted based on IP address tables.

## How to run

- `cargo fix --bin "ip-ranger"` - to fix code through an auto linter
- `cargo update` - to update dependencies
- `cargo build` - to build the binary
- `cargo run` - to run the binary

## How to test

- `cargo test` - to run the tests
